# Source Brief (as received)

The candidate brief was supplied in summarised form in the task prompt; no separate
brief file was present in the repository. This file records that source text verbatim so
that every requirement labelled **SOURCE** in [00_REQUIREMENTS.md](00_REQUIREMENTS.md)
can be traced back to it.

> The core requirement is:
>
> - Accept documents at runtime
> - Create a RAG application over those documents
> - Allow users to ask questions and receive grounded answers
> - Work with different document sets without code changes
> - Architecture, stack, models, tools and approach are up to us
>
> The submission requires:
>
> 1. A Git repository containing the working code
> 2. Complete AI-agent transcripts
> 3. Strong architectural reasoning and documentation

The rest of the task prompt (documentation list, engineering principles, component
trade-offs to evaluate, self-review questions) is the **candidate's own engineering
specification** for how the work should be done. It is tracked separately in
00_REQUIREMENTS.md as `SPEC` so it isn't mistaken for an assessment requirement.
